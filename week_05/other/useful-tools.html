Useful Tools

  • CSS 3 Generator
  • Nu Html Checker
  • HTML Validator for Chromium Browsers
  • Adobe Color Tools Main Page
    1. Adobe Color Wheel Palette Generator
  • Technically an educational game, CSS Grid Garden teaches about grid styling by having users write code to water garden patches.
  • Layout It! Grid Generator, a visual tool to build grids for web pages.
  • The website animista.net is a handy tool for creating CSS animations without writing a ton of code.
  • ASCII-Code, a website with useful and fun information about ASCII character encoding, including a Windows-1252 Extended ASCII lookup table on the home page, and ASII Art.
  • W3.CSS Tutorial, a lightweight alternative to Bootstrap on the W3Schools site.
  • On a related note, here is the W3Schools Boostrap 5 page.
  • Squoosh is a web-based image compressor.
  • Videomass is a GUI for FFmpeg, as is FFmpegGUI. Videomass is written in Python, by the way, and is cross-platform. FFmpegGUI is written in Swift, and is not to be confused with ffmpeg-guiffmpeg-gui written in Qt. QWinFF, (also here) also written in Qt, is available across multiple platforms, (Windows, Ubuntu, even OS/2!) however not on Macintosh (macOS). There is also Video Commander, which is free for personal and non-commercial use, or paid (currently $39 as of 2026) for commercial use.
  • Just for fun, an article about "installing Linux on a dead badger". It is from 2004.

Step 4

If you want to do more advanced configuration, opening the comprehensive programmer allows you to make more changes, first, being able to save the road name, road number, and other information that is only stored in the JMRI roster, not in the decoder.  

Besides being able to configure more basic settings, such as light or other function outputs, appropriate tabs for motor speed settings, sound (including volume levels, which horn or whistle, bell speed, etc. as supported) will be displayed.  Configuration Variables (CVs) are at the core of how this works.  The value stored in a CV determines what capabilities are enabled on a decoder, as well other things such as normal direction of travel when a throttle is set to forward or reverse.  JMRI DecoderPro makes it a lot easier to do this, because instead of needing to know the values yourself most of the time, JMRI can set them for you based on sliders or at least provide more information about them, such as entering the starting voltage or numerical acceleration and deceleration rates. A tab for consisting settings for running multiple locomotives together on the same train, which will also show up if the decoder supports it.  You can write all the changes on a sheet, the entire sheet, all changes on all sheets, and all sheets in total.  You can also attempt to read back changes, an entire sheet, or all sheets (which is slow) if the decoder supports it.  Most decoders support CV read-back, except for some made by MRC, although most will require some suitable load such as a motor, for it to work.  Sound decoders may also support verbal acknowledgement of a CV’s value, useful in other situations where CV read-back fails, either when programming a locomotive on the main track or if insufficient power is available on a dedicated programming track.

Git and GitHub

1. Understanding Git and GitHub

Git is Local Software for version control. It is native to a computer and runs directly on it. GitHub is a website and cloud service that Microsoft bought for storing and managing code online, frequently used to collaborate between multiple (sometimes many) people on software projects.

2. VS Code Source Control Process

Commit messages help provide context explaining the purpose of a change, addition, or subtraction/removal. They can help others to understand how a file or collection of files has changed over time. When someone writes a message it causes them to think about, consider, and make a summary of what they have done. Shorter and clear messages are best, using action verbs to begin. A generic message will be unclear and unhelpful. In VS Code, the Source Control Panel is used for this purpose. For me: Go to Source Control. Find the Untracked U in green under “Changes”. Add a message for the commit. Click on the blue Commit button. Then click on the blue button that reads Sync Changes or Push to upload the commit to GitHub. After this is done, the updates should show up in the appropriate location on GitHub.
